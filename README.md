# Hospital Readmission Prediction

## Project Title
Hospital Readmission Prediction Using Machine Learning

## Problem Statement
Hospital readmissions increase healthcare costs and indicate poor patient outcomes. Predicting patient readmission can help hospitals improve treatment planning and resource utilization.

## Objective
The objective of this project is to build a machine learning model that predicts whether a patient will be readmitted to the hospital within 30 days based on medical and demographic data.

## Dataset Description
The dataset contains patient demographic information, medical history, hospital stay details, and readmission status.
The dataset used in this project is a publicly available, de-identified hospital readmission dataset commonly used for academic and machine learning practice.

## Methodology / Approach
1. Data collection from a public dataset
2. Data cleaning and preprocessing
3. Feature selection
4. Model training using Logistic Regression
5. Model evaluation using accuracy metrics

## Tools & Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Steps to Run the Project
1. Install required Python libraries
2. Open the Jupyter Notebook file
3. Run all cells to train and test the model

## Results / Output
The model successfully predicts hospital readmission with acceptable accuracy.
